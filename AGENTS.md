# Ecological Computing umbrella instructions

Read README.md and SUITE.md before changing domain documentation.

- This repository contains the domain catalogue and shared development conventions.
- The three processing tools are independent sibling repositories with their own environments and Git histories.
- soil_organic_carbon is an ordinary directory, not an established software repository.
- Do not copy processing source, local environments or datasets into this umbrella.
- Preserve formulas, units, channel assumptions and the distinction between numerical results and visualisations.
- Keep historical inspection findings separate from current development status.
- Documentation work does not authorise algorithm changes. Record functional issues as separate development tasks.
- Read project-specific instructions before explicitly authorised cross-project work.
- Keep documentation portable; do not invent publication URLs or add filesystem-relative links to sibling repositories.
- Preserve Git history. Do not introduce submodules, subtrees or a shared runtime package without approval.
- Do not select licences, configure remotes or publish without explicit approval.
